Web Hosting y Dominios

¿Cómo podemos publicar una página web en Internet?

¿Qué es Web Hosting?

El Web Hosting es un servicio que permite almacenar los archivos de un sitio web en un servidor conectado a Internet. De esta manera, los usuarios pueden acceder a la página desde un navegador.

Tipos de Hosting

Tipo Descripción
Compartido Varios sitios utilizan recursos del mismo servidor.
VPS Un servidor virtual con recursos más controlados.
Nube Utiliza infraestructura distribuida para alojar aplicaciones.

¿Qué es Vercel?

Vercel es una plataforma utilizada para desplegar aplicaciones y sitios web. Permite conectar un repositorio de GitHub y publicar el proyecto en Internet.

¿Qué es un dominio?

Un dominio es el nombre que las personas utilizan para acceder a un sitio web en Internet.

Ejemplo:


minutafresh.com

TLD

TLD significa dominio de nivel superior. Es la parte final de un dominio.

  • .com — utilizado principalmente por sitios comerciales.
  • .org — común en organizaciones.
  • .net — originalmente relacionado con redes.

Subdominio

Un subdominio es una sección que se coloca antes del dominio principal. 


blog.minutafresh.com

¿Qué es DNS?

DNS significa Domain Name System. Su función principal es relacionar los nombres de dominio con las direcciones IP de los servidores.

Proceso de propagación DNS

1. Registrar

Se registra el dominio que queremos utilizar.

2. Configurar DNS

Se indican los servidores donde se encuentra el sitio.

3. Propagación

La información DNS se actualiza progresivamente.

4. Acceso

Finalmente, el navegador puede encontrar el sitio.

Flujo


DOMINIO
   ↓
DNS
   ↓
SERVIDOR
   ↓
HOSTING
   ↓
SITIO WEB
   ↓
NAVEGADOR
