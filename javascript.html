JavaScript Vanilla

El comportamiento de una página web.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado para agregar interacción y comportamiento a las páginas web.

HTML, CSS y JavaScript

Tecnología Función Ejemplo
HTML Estructura Textos, imágenes y botones.
CSS Estilo Colores y diseño.
JavaScript Comportamiento Responder a un clic.

Conceptos básicos

  • Variables: almacenan información.
  • Funciones: agrupan instrucciones.
  • Eventos: permiten responder a acciones.

Ejemplo práctico

function saludar() {
    document.getElementById("salida").textContent =
        "¡Hola desde JavaScript!";
}

Eventos

Algunos eventos comunes son click, mouseover, change y submit.
