JSON

JavaScript Object Notation para el intercambio de información.

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato de texto utilizado para almacenar y transportar información. Es muy utilizado para la comunicación entre aplicaciones web, servidores y APIs.

Estructura básica

JSON utiliza pares de clave y valor. 


{
    "nombre": "Minuta de Fresa",
    "precio": 2.50,
    "disponible": true
}

Objetos y arreglos


{
    "minutas": [
        {
            "nombre": "Fresa",
            "precio": 2.50
        },
        {
            "nombre": "Mango",
            "precio": 2.75
        },
        {
            "nombre": "Tamarindo",
            "precio": 2.50
        }
    ]
}

Objeto JavaScript vs cadena JSON

Objeto JavaScript JSON 

const minuta = {
    nombre: "Fresa",
    precio: 2.50
};


{
    "nombre": "Fresa",
    "precio": 2.50
}

JSON y las aplicaciones web

Cuando una aplicación necesita información de un servidor, puede recibir los datos en formato JSON. Por ejemplo, una aplicación podría solicitar una lista de minutas disponibles y recibir los nombres, precios e ingredientes mediante JSON.

Ejemplo con una API


fetch("https://ejemplo.com/minutas")
    .then(respuesta => respuesta.json())
    .then(datos => {
        console.log(datos);
    });

En este ejemplo, JavaScript solicita información y convierte la respuesta a un objeto que puede utilizar la aplicación.
