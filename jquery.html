jQuery

Una librería que facilita el trabajo con JavaScript.

¿Qué es jQuery?

jQuery es una librería de JavaScript creada para simplificar tareas comunes como manipular elementos HTML, manejar eventos y crear efectos y animaciones.

¿Por qué nació?

jQuery nació para facilitar el desarrollo web y evitar parte de las diferencias que existían entre los navegadores. Su sintaxis permitió escribir algunas operaciones de forma más corta.

Sintaxis básica


$("#titulo").hide();

$(".boton").click(function() {
    alert("Hola");
});

El símbolo $ es una parte característica de la sintaxis de jQuery y se utiliza para seleccionar elementos.

Ventajas

  • Sintaxis sencilla.
  • Facilita la manipulación del DOM.
  • Incluye efectos y animaciones.
  • Fue muy útil para compatibilidad entre navegadores.

Desventajas

  • Puede ser innecesario para proyectos modernos sencillos.
  • Agrega una dependencia externa.
  • JavaScript moderno ya incorpora muchas funciones similares.
