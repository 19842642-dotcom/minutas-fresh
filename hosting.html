Web Hosting y Dominios

Cómo publicar una página web en internet.

¿Qué es Web Hosting?

El hosting es un servicio que permite almacenar los archivos de un sitio web para que otras personas puedan acceder a ellos mediante internet.

Tipos de Hosting

Compartido

Varios sitios utilizan recursos del mismo servidor.

VPS

Servidor virtual con mayor control y recursos asignados.

Nube

Utiliza infraestructura distribuida para alojar sitios y aplicaciones.

Vercel

Vercel es una plataforma que permite desplegar proyectos web. Puede conectarse con GitHub y publicar automáticamente los cambios realizados en el repositorio.

¿Qué es un dominio?

Un dominio es el nombre que una persona utiliza para acceder a un sitio web.

TLD

El TLD es la terminación de un dominio. Algunos ejemplos son:

.com

Uso comercial y general.

.net

Relacionado originalmente con redes.

.org

Utilizado frecuentemente por organizaciones.

Subdominio

Un subdominio es una parte que aparece antes del dominio principal.

Ejemplo: blog.ejemplo.com

Propagación DNS

1

Se registra el dominio.

2

Se configuran los DNS.

3

Los cambios se distribuyen.

4

El sitio queda disponible.
