JavaScript

El lenguaje que agrega comportamiento e interactividad a las páginas web.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado principalmente para agregar interactividad y comportamiento a las páginas web. Permite responder a acciones realizadas por los usuarios.

HTML, CSS y JavaScript

Tecnología Función
HTML Define la estructura y contenido de la página.
CSS Controla los colores, tamaños, posiciones y diseño.
JavaScript Agrega comportamiento e interactividad.

Conceptos básicos

  • Variables: almacenan información.
  • Funciones: contienen instrucciones que realizan una tarea.
  • Eventos: permiten responder a acciones como click, mouseover o teclado.

Ejemplo práctico


let sabor = "Fresa";

function mostrarSabor() {
    alert("Elegiste una minuta de " + sabor);
}

document.getElementById("boton")
    .addEventListener("click", mostrarSabor);

¿Cómo funciona?

En este ejemplo se crea una variable llamada sabor. Después se crea una función llamada mostrarSabor(). Finalmente, JavaScript detecta cuando el usuario hace clic en un botón y ejecuta la función.
