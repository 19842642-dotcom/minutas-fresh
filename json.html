JSON

Formato utilizado para intercambio de datos.

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato de texto utilizado para representar y transportar información.

Estructura básica

{
    "nombre": "Minuta de Fresa",
    "precio": 2.50,
    "sabor": "Fresa"
}

Objeto JavaScript y cadena JSON

Objeto JavaScript Cadena JSON
{ nombre: "Fresa", precio: 2.50 } { "nombre": "Fresa", "precio": 2.50 }

JSON en aplicaciones web

Las aplicaciones web utilizan JSON para enviar y recibir datos desde servidores y APIs. 

const producto = JSON.parse(textoJSON);

console.log(producto.nombre);
