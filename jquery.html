jQuery

Una librería de JavaScript.

¿Qué es jQuery?

jQuery es una librería de JavaScript que facilita tareas como seleccionar elementos, manejar eventos y realizar efectos.

¿Por qué nació?

Nació para simplificar tareas frecuentes del desarrollo web y facilitar el trabajo con diferentes navegadores.

Sintaxis básica

$("#mensaje").hide();

$("#mensaje").fadeIn();

Ventajas

  • Es fácil de aprender.
  • Su sintaxis es corta.
  • Incluye diferentes efectos.

Desventajas

  • JavaScript moderno tiene muchas funciones nativas.
  • Es necesario cargar una librería adicional.
